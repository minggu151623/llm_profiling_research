# What this study can establish

**Names have already been used for static branch-probability prediction.** In LLVM, Raman and Li embedded callee names from control-dependent blocks, alongside structural features, and trained against edge probabilities derived from SamplePGO. The PLATO group later described adding signature embeddings to GraalNN. The proposed contribution is a measured comparison of frozen SLM predictions and representations against structural and lexical predictors on the same original JVM bytecode jumps and input families. [Raman and Li, §4.3](https://arxiv.org/html/2202.06728) · [PLATO, Embeddings](https://plato.matf.bg.ac.rs/?content=research_graalvm_sprof) · [Registered protocol](../../experiments/study/protocol.md)

## What the measurements now show

| Decision | Measured outcome | Evidence |
| --- | --- | --- |
| Select structural baselines | Fitted structural and lexical models reach held-out macro MAE 0.311–0.326, against 0.429 for a constant 0.5. Every selected site jumps forward, so the offset-direction rule predicts 0 throughout and scores 0.471. | [Metrics](../../experiments/study/evaluation/metrics.csv) |
| Isolate the value of names | Masking names changes either SLM readout by at most 0.003 macro MAE. The embedding ridge matches lexical ridge (+0.002, interval −0.022 to 0.024). The study therefore finds no measurable value of names beyond lexical regression for this model. | [Paired deltas](../../experiments/study/evaluation/paired_deltas.csv) · [Masking contrasts](../../experiments/study/supplement/sensitivity.csv) |
| Justify a zero-run SLM comparison | The prompted 0–9 rating spans only 0.339–0.489 and does not rank sites (Spearman −0.04). It is 0.099 worse than lexical ridge (0.050 to 0.152) and worse in all eight projects. | [Per-site predictions](../../experiments/study/evaluation/predictions.csv) |
| Test whether a larger checkpoint helps (exploratory) | Qwen2.5-Coder-1.5B with the same prompts, readouts and folds: zero-shot MAE 0.435 (Spearman 0.02), embedding ridge 0.326, +0.001 (−0.023 to 0.024) from lexical ridge and −0.001 from the 0.49B readout. | [1.5B contrasts](../../experiments/study/supplement/scale.csv) · [Diagnostics](../../experiments/study/supplement/scale_summary.json) |
| Quantify transfer | Seen-project fits reach 0.133–0.137 on the shifted workload, but copying each site's own normal label reaches 0.088. The gain comes from labels at the same site and does not transfer to new libraries. | [Seen-project fits](../../experiments/study/evaluation/folds.json) · [Persistence](../../experiments/study/supplement/persistence.csv) |
| Quantify workload sensitivity | 42 of 138 matched sites move by more than 0.10 when the mixture reverses. Any workload-blind prediction scored on both workloads has macro MAE of at least 0.044. | [Workload shift](../../experiments/study/evaluation/workload_shift.csv) |

The contribution that survives measurement is a negative result with a reproducible protocol. On original JVM bytecode jumps with held-out libraries, a frozen 0.49B code model adds no accuracy over lexical and structural regression, and workload identity bounds what any static estimate can achieve. An exploratory rerun with the 1.5B checkpoint of the same family gave the same result. This does not test much larger or fine-tuned models, other prompts or token-level readouts. [Manuscript](../../paper/manuscript.md)

The empirical scope is selected library classes, controlled API calls, one registered small model with an exploratory 1.5B check, and specified baselines. Manuscript claims about which model performs better must point to paired results and uncertainty. Priority, production workload representativeness and compiler throughput require additional evidence.
